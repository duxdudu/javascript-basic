📦 Variables

A variable is a named container that holds a value. JavaScript has three ways to create variables.

1. var — the old way

var was the original way. It works, but has quirks (it ignores block scope). Avoid it in new code. 

var name = "Alice";
                  var age  = 25;
                  console.log(name); // Alice

2. let — use this for values that change

let creates a variable you can reassign later.

let score = 0;
                score = 10;       // ✅ allowed — we changed it
                score = score + 5;
                console.log(score); // 15

3. const — use this for values that stay the same

const creates a variable you cannot reassign. Use it by default. 

const PI = 3.14159;
        // PI = 3; ❌ Error — cannot reassign a const

        const userName = "Bob";
        console.log(userName); // Bob

4. Naming Rules


        // ✅ Good names
              let firstName = "Alice";   // camelCase — standard in JS
              let totalScore = 100;
              const MAX_SIZE = 50;       // ALL_CAPS for true constants

              // ❌ Bad names
              // let 1name = "x";        // cannot start with a number
              // let my-name = "x";      // hyphens not allowed
              // let let = "x";          // reserved word
