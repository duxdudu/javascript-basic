🌐 DOM Manipulation

The DOM (Document Object Model) is how JavaScript reads and changes what's on the page — text, styles, elements, everything.

1. Selecting elements


      // By ID — returns one element
                const btn = document.getElementById("myBtn");

                // By CSS selector — returns the FIRST match
                const title = document.querySelector("h1");
                const box   = document.querySelector(".card");
                const input = document.querySelector("#nameInput");

                // By CSS selector — returns ALL matches (a NodeList)
                const allBtns = document.querySelectorAll("button");
                const allCards = document.querySelectorAll(".card");

2. Reading and changing text

const heading = document.querySelector("h1");

// Read the text
console.log(heading.textContent); // "DOM Manipulation"

// Change the text
heading.textContent = "Hello World!";

// innerHTML lets you set HTML tags too
const box = document.querySelector("#box");
box.innerHTML = "<strong>Bold text</strong>";

3. Changing styles

const box = document.querySelector("#box");

// Change CSS directly
box.style.color           = "red";
box.style.backgroundColor = "yellow";
box.style.fontSize        = "20px";
box.style.display         = "none";   // hide
box.style.display         = "block";  // show

4. Adding and removing CSS classes

const btn = document.querySelector("#myBtn");

btn.classList.add("active");       // add a class
btn.classList.remove("active");    // remove a class
btn.classList.toggle("active");    // add if missing, remove if present
btn.classList.contains("active");  // true or false — check if it has the class

5. Creating and adding new elements

// Create a new element
const li = document.createElement("li");
li.textContent = "New item";

// Add it to an existing element
const list = document.querySelector("#myList");
list.appendChild(li);   // add at the END

// Remove an element
li.remove();

6. Reading input values

const input = document.querySelector("#nameInput");

// Read what the user typed
const value = input.value;
console.log(value);

// Clear the input
input.value = "";

// Focus the input (put cursor in it)
input.focus();
