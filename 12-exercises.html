✏️ JavaScript Exercises

Practice what you've learned. Try to solve each exercise on your own before looking at the hints.

📦 Variables & Data Types

Exercise 1: Create Variables

Easy

Task: Create variables to store the following information about yourself:

  • Your first name (string)
  • Your age (number)
  • Whether you are a student (boolean)
  • Your favorite color (string)

Then log each variable to the console.

Hint: Use const for values that won't change. Use console.log() to print.

Exercise 2: Check Data Types

Easy

Task: Create 5 different variables with different data types (string, number, boolean, null, undefined). Use typeof to check and log the type of each one.

Hint: console.log(typeof myVariable);

➕ Operators & Math

Exercise 3: Simple Calculator

Easy

Task: Create two variables with numbers. Then calculate and log:

  • Their sum
  • Their difference
  • Their product
  • Their quotient
  • The remainder when dividing them
Hint: Use +, -, *, /, and %

Exercise 4: Age Checker

Easy

Task: Create a variable age. Write code that checks if the person is 18 or older. If yes, log "You can vote". If no, log "You are too young to vote".

Hint: Use an if/else statement with the >= operator.

🔀 Conditionals

Exercise 5: Grade Calculator

Medium

Task: Create a variable score (0-100). Write code that assigns a letter grade:

  • 90-100: A
  • 80-89: B
  • 70-79: C
  • 60-69: D
  • Below 60: F

Log the grade to the console.

Hint: Use if/else if/else statements.

Exercise 6: Day of the Week

Medium

Task: Create a variable day with a number 1-7. Use a switch statement to log the day name (1 = Monday, 2 = Tuesday, etc.). If the number is invalid, log "Invalid day".

Hint: Use switch(day) with case for each number and default for invalid input.

🔁 Loops

Exercise 7: Count to 10

Easy

Task: Use a for loop to log numbers 1 through 10 to the console.

Hint: for (let i = 1; i <= 10; i++) { ... }

Exercise 8: Even Numbers Only

Medium

Task: Use a for loop to log only the even numbers from 1 to 20.

Hint: Use if (i % 2 === 0) inside the loop to check if a number is even.

Exercise 9: Sum of Numbers

Medium

Task: Use a loop to calculate the sum of all numbers from 1 to 100. Log the result.

Hint: Create a variable sum = 0 before the loop, then add each number to it: sum += i

⚙️ Functions

Exercise 10: Greeting Function

Easy

Task: Write a function called greet that takes a name as a parameter and returns "Hello, [name]!". Call the function with different names and log the results.

Hint: function greet(name) { return "Hello, " + name + "!"; }

Exercise 11: Is Even Function

Easy

Task: Write a function isEven that takes a number and returns true if it's even, false if it's odd.

Hint: Use the modulo operator: return num % 2 === 0;

Exercise 12: Max of Two Numbers

Medium

Task: Write a function max that takes two numbers and returns the larger one.

Hint: Use an if statement or the ternary operator: return a > b ? a : b;

Exercise 13: Celsius to Fahrenheit

Medium

Task: Write a function that converts Celsius to Fahrenheit. Formula: F = (C × 9/5) + 32

Hint: function toFahrenheit(c) { return (c * 9/5) + 32; }

📋 Arrays

Exercise 14: Create and Access Array

Easy

Task: Create an array of 5 fruits. Log the first fruit, the last fruit, and the total number of fruits.

Hint: Use array[0] for first, array[array.length - 1] for last, array.length for count.

Exercise 15: Add and Remove Items

Easy

Task: Start with an empty array. Add 3 items using push. Remove the last item using pop. Log the array after each operation.

Hint: arr.push("item") and arr.pop()

Exercise 16: Loop Through Array

Easy

Task: Create an array of numbers. Use a for loop to log each number multiplied by 2.

Hint: for (let i = 0; i < arr.length; i++) { console.log(arr[i] * 2); }

Exercise 17: Filter Array

Medium

Task: Create an array of numbers from 1 to 10. Use filter to create a new array with only numbers greater than 5.

Hint: const filtered = numbers.filter(n => n > 5);

Exercise 18: Map Array

Medium

Task: Create an array of names. Use map to create a new array where each name is converted to uppercase.

Hint: const upper = names.map(name => name.toUpperCase());

Exercise 19: Sum Array

Medium

Task: Create an array of numbers. Write a function that takes the array and returns the sum of all numbers.

Hint: Use a loop or reduce: arr.reduce((sum, n) => sum + n, 0)

🗂️ Objects

Exercise 20: Create a Person Object

Easy

Task: Create an object representing a person with properties: name, age, city, and isStudent. Log each property.

Hint: const person = { name: "Alice", age: 25, ... };

Exercise 21: Object with Method

Medium

Task: Create a car object with properties: brand, model, year. Add a method getInfo that returns a string like "2020 Toyota Camry".

Hint: getInfo: function() { return this.year + " " + this.brand + " " + this.model; }

Exercise 22: Array of Objects

Medium

Task: Create an array of 3 book objects. Each book should have: title, author, pages. Use forEach to log each book's title.

Hint: books.forEach(book => console.log(book.title));

🌐 DOM Manipulation

Exercise 23: Change Text Content

Easy

Task: Create an HTML page with a paragraph that says "Original text". Use JavaScript to change it to "Text changed by JavaScript".

Hint: document.querySelector("p").textContent = "Text changed by JavaScript";

Exercise 24: Change Styles

Easy

Task: Create a div with some text. Use JavaScript to change its background color to blue and text color to white.

Hint: element.style.backgroundColor = "blue"; element.style.color = "white";

Exercise 25: Add Elements

Medium

Task: Create an empty <ul> in HTML. Use JavaScript to add 5 list items to it with the text "Item 1", "Item 2", etc.

Hint: Use a loop, document.createElement("li"), and ul.appendChild(li)

🖱️ Events

Exercise 26: Button Click

Easy

Task: Create a button. When clicked, it should log "Button clicked!" to the console.

Hint: button.addEventListener("click", () => console.log("Button clicked!"));

Exercise 27: Input Value

Easy

Task: Create an input field and a button. When the button is clicked, log the value of the input to the console.

Hint: const value = input.value;

Exercise 28: Counter

Medium

Task: Create a counter that starts at 0. Add a button that increases the counter by 1 each time it's clicked. Display the current count on the page.

Hint: Use a variable let count = 0; and update a paragraph's textContent on each click.

Exercise 29: Keyboard Event

Medium

Task: Create an input field. Log to the console every key that the user presses while typing.

Hint: input.addEventListener("keydown", (e) => console.log(e.key));

💾 localStorage

Exercise 30: Save and Load Name

Easy

Task: Create an input field and a "Save" button. When clicked, save the input value to localStorage. When the page loads, display the saved name if it exists.

Hint: localStorage.setItem("name", value) and localStorage.getItem("name")

Exercise 31: Save Array to localStorage

Medium

Task: Create a simple todo list. When the user adds a task, save the entire array to localStorage using JSON. When the page loads, load and display the saved tasks.

Hint: localStorage.setItem("tasks", JSON.stringify(tasks)) and JSON.parse(localStorage.getItem("tasks"))

🏆 Challenge Projects

Challenge 1: Number Guessing Game

Hard

Task: Build a game where the computer picks a random number between 1-100. The user guesses, and the program says "too high", "too low", or "correct!".

  • Generate random number: Math.floor(Math.random() * 100) + 1
  • Use an input field and button
  • Keep track of number of guesses
  • Show feedback after each guess

Challenge 2: Shopping Cart

Hard

Task: Build a simple shopping cart where users can:

  • Add items with name and price
  • Display all items in a list
  • Remove items
  • Show the total price
  • Save the cart to localStorage

Challenge 3: Quiz App

Hard

Task: Build a quiz with 5 multiple-choice questions. Features:

  • Show one question at a time
  • Track the user's score
  • Show results at the end
  • Add a "Restart Quiz" button

Challenge 4: Weather Dashboard (Bonus)

Hard

Task: Create a weather app that:

  • Takes a city name as input
  • Fetches weather data from a free API (like OpenWeatherMap)
  • Displays temperature, conditions, and an icon
  • Saves the last searched city to localStorage
Hint: Use fetch() to get data from an API. This requires learning about Promises and async/await.

🎯 How to Use These Exercises

  1. Start from Exercise 1 and work your way down
  2. Try to solve each one WITHOUT looking at the hint first
  3. If you're stuck for more than 10 minutes, read the hint
  4. Test your code in the browser console or create a separate HTML file
  5. Don't skip exercises — each one builds on previous concepts
  6. After finishing all exercises, try the challenge projects
