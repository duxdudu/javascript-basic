💾 localStorage

localStorage lets you save data in the browser. The data stays there even after the page is refreshed or the browser is closed.

1. Saving data — setItem

// localStorage.setItem("key", "value")
// Both key and value must be strings

localStorage.setItem("username", "Alice");
localStorage.setItem("theme", "dark");
localStorage.setItem("score", "100");

2. Reading data — getItem

const username = localStorage.getItem("username");
console.log(username); // "Alice"

// If the key doesn't exist, you get null
const missing = localStorage.getItem("nothing");
console.log(missing); // null

3. Removing data

// Remove one item
localStorage.removeItem("theme");

// Remove everything
localStorage.clear();

4. Saving objects and arrays — use JSON

localStorage only stores strings. To save objects or arrays, convert them with JSON.stringify and JSON.parse.

// Saving an object
const user = { name: "Alice", age: 25 };
localStorage.setItem("user", JSON.stringify(user));

// Reading it back
const saved = localStorage.getItem("user");
const parsed = JSON.parse(saved);
console.log(parsed.name); // "Alice"

// Saving an array
const tasks = ["Buy milk", "Read book", "Exercise"];
localStorage.setItem("tasks", JSON.stringify(tasks));

// Reading it back
const savedTasks = JSON.parse(localStorage.getItem("tasks"));
console.log(savedTasks[0]); // "Buy milk"

5. Safe pattern — handle missing data

function loadTasks() {
  const saved = localStorage.getItem("tasks");

  // If nothing saved yet, return an empty array
  if (saved === null) {
    return [];
  }

  return JSON.parse(saved); // convert string back to array
}

function saveTasks(tasks) {
  localStorage.setItem("tasks", JSON.stringify(tasks));
}

// Usage
let tasks = loadTasks();
tasks.push("New task");
saveTasks(tasks);

6. How it's used in the Task Manager

// From app.js in the Task Manager project:

// Load tasks when page opens
function loadTasks() {
  const saved = localStorage.getItem("tasks");
  tasks = saved ? JSON.parse(saved) : [];
