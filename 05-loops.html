🔁 Loops

Loops repeat a block of code multiple times so you don't have to write the same thing over and over.

1. for loop — when you know how many times

// for (start; condition; step)
for (let i = 1; i <= 5; i++) {
  console.log("Count: " + i);
}
// Count: 1
// Count: 2
// Count: 3
// Count: 4
// Count: 5

2. Looping through an array

const fruits = ["apple", "banana", "cherry"];

for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

// Cleaner way — for...of
for (const fruit of fruits) {
  console.log(fruit);
}
// apple  banana  cherry

3. while loop — when you don't know how many times

let count = 0;

while (count < 5) {
  console.log("count is " + count);
  count++; // ⚠️ always update or it loops forever!
}
// count is 0 ... count is 4

4. do...while — runs at least once

let number = 10;

do {
  console.log("number is " + number);
  number++;
} while (number < 5);

// Runs once even though 10 is not less than 5
// Output: number is 10

5. forEach — loop built into arrays

const names = ["Alice", "Bob", "Charlie"];

names.forEach(function(name) {
  console.log("Hello, " + name + "!");
});

// Arrow function version (shorter)
names.forEach(name => console.log("Hi " + name));

6. break and continue

// break — stop the loop early
for (let i = 0; i < 10; i++) {
  if (i === 5) break;
  console.log(i); // 0 1 2 3 4
}

// continue — skip this step, keep going
for (let i = 0; i < 6; i++) {
  if (i === 3) continue;
  console.log(i); // 0 1 2 4 5
}
