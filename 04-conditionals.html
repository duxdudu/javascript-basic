🔀 Conditionals

Conditionals let your code make decisions — run different code depending on whether something is true or false.

1. if statement

const age = 20;

if (age >= 18) {
  console.log("You are an adult.");
}
// Only runs if the condition is true

2. if / else

const age = 15;

if (age >= 18) {
  console.log("You can vote.");
} else {
  console.log("You are too young to vote.");
}
// else runs when the condition is false

3. if / else if / else — multiple conditions

const score = 72;

if (score >= 90) {
  console.log("Grade: A");
} else if (score >= 80) {
  console.log("Grade: B");
} else if (score >= 70) {
  console.log("Grade: C");
} else {
  console.log("Grade: F");
}
// Output: Grade: C

4. switch statement — for exact matches

const day = "Monday";

switch (day) {
  case "Monday":
    console.log("Start of the week!");
    break;
  case "Friday":
    console.log("Almost weekend!");
    break;
  case "Saturday":
  case "Sunday":
    console.log("It's the weekend!");
    break;
  default:
    console.log("A regular day.");
}
// Output: Start of the week!

5. Ternary Operator — short if/else in one line

const age = 20;

// condition ? valueIfTrue : valueIfFalse
const status = age >= 18 ? "adult" : "minor";
console.log(status); // "adult"

// Same as:
// if (age >= 18) { status = "adult" } else { status = "minor" }
